# DIODE 909

TR-909 drum machine for Max for Live by Transistor Labs: the x0x step sequencer of DIODE 808 with the
**DIODE 909 circuit engine** — circuit-level BD, SD, toms, RS and CP; hi-hats, crash and ride through
the 909's sample playback circuits, built into the external.

- `m4l/device/DIODE 909.amxd` — the device (unfrozen), built by `m4l/tools/make_patch.py`
- `m4l/code/` — panel (`diode909_seq.js`, generated by `m4l/tools/make_seq.py`) and pattern data script
- `m4l/source/diode909_tilde` — the `diode909~` external (11 sample-accurate trigger inlets, stereo out, flam)
- `Engine.*`, `machines/tr909` — the TR-909 voice board
- `roms/tr909-roms.tar.enc` — the sample ROMs, AES-256 encrypted; CI decrypts them with the `ROM_KEY` secret.
  The build fails if a ROM is missing or wrong.
- `m4l/docs/` — user manual and update history (`build_docs.py`, panel pictures by `render_panel.py`)

CI (`.github/workflows/m4l.yml`) runs only on a `[release]` commit or a manual run, and uploads a
password-protected `.7z` (password: `ROM_KEY`) as a workflow artifact.
